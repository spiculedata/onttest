# Data quality checks

Generated by `brackenfield run` from the check registry and the pandera contracts. Do not edit by hand.

Severity: **error** = wrong or unusable as written (goes to Priya); **warning** = readable but suspicious (goes to Priya); **info** = handled automatically by a documented rule (logged only).
