⏺ That's mostly built already. The connector writes into the same database and
  links each device to the machine records. But it doesn't meet "the second run
  must change nothing" yet. Two things are wrong:

  1. The raw device table grows on every run. It appends a full copy of the
     device list each time.
  2. clean.devices holds run-specific values. last_seen_at and run_id differ on
     every run, even when nothing in FieldTrax changed.

  There's also no report of what changed between runs. My plan:

  - Store device changes only. Keep a version table that gets a new row only
    when a device's details or listing actually change. Remove the per-run
    timestamps from the clean records.
  - Diff every run. Compare the clean tables before and after loading, field by
    field, and save the result to meta.record_changes and out/changes.md.
    "Changed nothing" is then something you can check, not just my claim.
  - Report device matching in the same file. List which devices matched which
    machines (and how), which devices match nothing, and which working machines
    have no tracker.
